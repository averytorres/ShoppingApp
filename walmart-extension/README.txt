HOME GROCERY HELPER — H-E-B AND WALMART

The folder name is historical. This Chrome helper supports both stores.

For installation, account connections and everyday use, read:
  ../docs/USER-GUIDE.md

For human checks, cart sync and connection problems, read:
  ../docs/TROUBLESHOOTING.md

For source setup, architecture and testing, read:
  ../CONTRIBUTING.md

In an installer setup, open http://127.0.0.1:4317/install for the connection
steps and exact helper folder. Chrome must approve Load unpacked manually.
Store sign-in stays in Chrome. This helper never submits checkout or payment.

Reload the helper at chrome://extensions after updating its files. Earlier
prototype behavior and test notes in Git history are not current instructions.
