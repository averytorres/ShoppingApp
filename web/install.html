YOUR HOUSEHOLD, CONNECTED

Three steps to your first shop

Set up the helper once on the hosting PC. Everyone else uses the website.

Checking the household server…

1. Add the Chrome helper

On this PC, open chrome://extensions in Chrome and turn on Developer mode. Choose Load unpacked, then select the folder below.

Chrome requires your approval. The helper is bundled with this installer; it is not yet published in the Chrome Web Store.

You can also find “Chrome extension folder” under Home Grocery in the Windows Start menu. After an app update, reload the helper on Chrome’s Extensions page.

2. Connect your store accounts

  1. Sign into H-E-B and/or Walmart in the Chrome profile you use for shopping. Complete any store human check privately.
  2. Open Home Grocery Helper from Chrome’s Extensions menu. Expand Household website.
  3. Keep the server address below, enter a friendly account nickname, and choose Connect household.

Different store logins? Use separate Chrome profiles and a distinct nickname for each. Keep Chrome available for cart and history syncing.

Open account and store settings

3. Open it on your phone

Connect to the same private home network, then open one of these addresses:

http://groceries.local

    If the friendly name does not work, try a numbered address above. Keep the hosting PC awake and signed into Windows. Use a Private Windows network profile; setup’s network option asks Windows to allow local access.

    No extension is needed on the phone. The helper on this PC updates the selected store account’s cart.

    Ready to build your first list?

    Browse your stores or collect purchase history from the helper to start learning your usual products. Review imported history before accepting it. Suggestions improve as real purchases are added.
